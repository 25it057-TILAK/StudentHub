
# StudentHub – Student Information Portal

StudentHub is a responsive student information portal developed as a Web Development Frameworks project.

The main purpose of StudentHub is to provide students with a single digital platform for accessing student information, college events, feedback, FAQs, profile information and other student services.

## 1. Project Objective

The objective of StudentHub is to create a simple, responsive and user-friendly web portal for college students.

StudentHub provides:

* Student information
* College events
* Student dashboard
* Student profile
* Registration and login pages
* Frequently Asked Questions
* Student feedback
* Contact information
* Admin interface

## 2. Target Users

### Student

Students can:

* Register an account
* Login to StudentHub
* View their dashboard
* View college events
* View and update profile information
* Submit feedback
* View FAQs
* Contact StudentHub

### Administrator

The administrator can access the admin section for managing student-related information and portal content.
