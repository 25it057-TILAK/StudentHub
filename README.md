# 🎓 StudentHub

StudentHub is a responsive student portal website developed as part of the Web Design & Frontend (WDF) course.

## 📌 Features

- 🏠 Home Page
- 👨‍🎓 Student Dashboard
- 📚 Course Information
- 📅 Timetable
- 📝 Assignments
- 📢 Notices
- 📞 Contact Page
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap (if used)

## 📂 Project Structure

```
StudentHub/
│── index.html
│── about.html
│── contact.html
│── css/
│── js/
│── images/
│── README.md
```

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/25it057-TILAK/StudentHub.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.
